## Overview

`hyperframes-motion-reel` asks Claude Code to behave like a senior motion designer. Give it a theme — optionally with character art, a voice track, a duration or an aspect ratio — and it plans the concept, design system, beat timeline, motion and sound, then implements and renders a HyperFrames project end-to-end.
