## 概要

`hyperframes-motion-reel` は Claude Code をトップクラスのモーションデザイナーとして動かします。テーマ（任意でキャラクター画像・ボイス・尺・アスペクト比）を渡すと、コンセプト・デザインシステム・拍タイムライン・モーション・サウンドを設計し、HyperFrames プロジェクトとして実装・レンダリングまで行います。
